# Last Text at One Percent

[![make.fun · u-azazex-last-text-at-one-percent-ba9fc876](https://make.fun/badge/u-azazex-last-text-at-one-percent-ba9fc876.svg)](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876)

One text message (130 characters), the last words of a phone dying at one percent battery, written by a program to `/output/entry.txt`. Node 22, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

## The text

> 1% left: tell my charger I loved it, delete my browser history, and remember me as the phone that died mid-text, not the one that—
